# Java Challenges

This directory will contain all the java challenges from Revature. Given that all classes are packaged, these functions need to be run from the root directory.

Most of these files contain functions that are commented out. To test all the functions, manual editing will need to be done to just uncomment functions to test.

## Core Java

These challenges are pulled from the Core Java slides provided by Revature during week 2. These challenge are in several places across the slides and will thus not be linked. However, the name of each function corresponds to the name of the challenge

The CoreJava challenges involve both the CoreJava.java file and the Repl.java file and thus to run both, must be compiled. Many of the functions are commented out at present and to test every function, some manual uncommenting will need to be done

The following commands compile and run the files:

```bash
javac javaChallenges/Repl.java javaChallenges\CoreJava.java
java javaChallenges.CoreJava
```

## SeptemberThird

This file refers to specific challenges provided on the third of September, 2026. These challenges were no explicitly put into the CoreJava slides and thus they have their own file.

The following commands compile and run the file:

```bash
javac challenges/SeptemberThird.java
java challenges.SeptemberThird
```
